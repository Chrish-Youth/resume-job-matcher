Edge / Chrome · 首次安装一次

安装或更新岗位采集扩展

岗位雷达依靠扩展自动切换搜索词并回传岗位。以前安装过时，请在扩展管理页点击一次“重新加载”。

  1. 打开扩展管理页Edge 输入 edge://extensions，Chrome 输入 chrome://extensions
  2. 开启“开发人员模式”首次安装选择“加载解压缩的扩展”；已有扩展点击“重新加载”
  3. 选择下面的扩展目录启动岗位雷达后无需再逐页点击扩展图标

扩展只读取当前网页可见的公开职位卡片，不读取账号、Cookie、聊天记录，也不会自动投递。
