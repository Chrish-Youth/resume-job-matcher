# 职得 · 简历岗位匹配助手

一个可本地运行的求职工作台：上传 DOCX、PDF 或 TXT 简历，通过通义千问、DeepSeek 或本地规则提取候选人画像，采集智联招聘与 BOSS 直聘的公开岗位，按求职条件筛选并生成个性化招呼语。

## 配置大模型

复制 `.env.example` 为 `.env`，填入你已有的 Key：

```powershell
Copy-Item .env.example .env
notepad .env
```

可以只配置一家，也可以同时配置：

```dotenv
DASHSCOPE_API_KEY=你的千问Key
DEEPSEEK_API_KEY=你的DeepSeekKey
LLM_PROVIDER=qwen
```

保存后重启应用，页面右上角即可切换模型。默认使用 `qwen-plus` 和 `deepseek-v4-flash`，也可通过 `QWEN_MODEL`、`DEEPSEEK_MODEL` 覆盖。

## 启动

直接双击项目目录中的：

```text
启动.bat
```

它会启动服务并自动打开 <http://127.0.0.1:8765/>。如果浏览器没有自动打开，也可以手动访问该地址。

命令行启动方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

## 当前能力

- 本地解析 DOCX / PDF / TXT，不向第三方上传文件
- 千问 / DeepSeek 提取姓名、学历、经历、技能和求职亮点
- 大模型分批评估全部候选岗位，并返回推荐依据、能力缺口和 A–D 匹配等级
- 大模型生成专业、直接、亲切三种风格的岗位招呼语
- 分析简历后可选自动启动岗位雷达，上传完即可连续采集，无需再手动点击
- 支持为当前结果前 15 个岗位批量生成招呼语，可逐条复制或整体导出 Markdown
- API 未配置或调用失败时自动回退本地规则
- 岗位雷达自动生成精准、相邻和能力可迁移三层职位搜索词
- 浏览器扩展按搜索计划自动切换智联招聘与 BOSS 直聘页面、滚动加载并连续采集
- 采集被验证码或登录拦截时自动暂停并提醒，处理完成后可一键恢复继续采集
- 定时雷达：设定每日时间后，只要浏览器到点运行就会自动采集并匹配新岗位，完成后发桌面通知
- 自动对比上一轮定时结果，在助手页面提示本轮新增岗位数量，一键载入
- 每份简历使用独立采集会话，避免上一轮岗位或其他页面的数据混入
- 先按目标城市、最低薪资和实习/应届条件过滤，再通过千问、DeepSeek 或本地规则匹配
- 最多保留 300 个岗位，先对全部岗位本地初筛，再用大模型精排前 60 个候选
- 自动合并跨关键词结果、统计重复岗位，并按重点推荐、可迁移和本轮新增分组
- 自动把结构化画像、岗位和筛选条件保存到当前浏览器本机，刷新后可恢复
- 模型结果在本机内存缓存 6 小时，减少重复调用和 API 消耗

## 隐私说明

- 本地规则模式：简历文件和文字均不离开本机。
- 云端模型模式：原始文件仍在本地解析，提取出的简历文字会发送给所选模型 API。
- 定时雷达会为自动运行保存一份简历画像到本地 `data/` 目录（已加入 .gitignore，不提交、不上传），可在定时设置中随时关闭。
- 后续岗位匹配与招呼语生成只发送必要的结构化画像，不重复发送简历预览、文件名、电话或邮箱。
- API Key 只由本机 Python 服务读取，不会返回给浏览器；`.env` 已加入 `.gitignore`。
- PDF 会先在本机提取文字，再按当前模型设置分析；不上传原始 PDF 文件。加密 PDF 和纯图片扫描件需先转为可复制文字的 PDF。
- 页面会把结构化画像、岗位和筛选条件保存到当前浏览器的本地存储；可点击右上角“清空本机记录”删除。

## 产品边界

初始岗位为演示数据；上传简历后可按求职城市和方向导入智联或 BOSS 的公开岗位，替换为真实岗位。

### 安装一键采集扩展

扩展目录为当前项目下的 `extension` 文件夹。首次使用：

1. Edge 地址栏输入 `edge://extensions`（Chrome 输入 `chrome://extensions`）。
2. 开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择项目中的 `extension` 文件夹，并将“职得岗位采集助手”固定到工具栏。

如果以前安装过旧版扩展，请在扩展管理页对“职得岗位采集助手”点击一次“重新加载”。

之后上传简历、确认城市和基本条件，点击“开始自动找工作”。系统会自动生成多组职位关键词，打开第一组搜索页；扩展会依次切换搜索词和平台、滚动读取可见岗位并回传。全部任务完成后，应用统一去重和匹配，不需要逐页点击扩展图标。

如果招聘网站出现登录、安全验证或页面无法识别，可以点击“停止并整理当前岗位”，已经采集的数据不会丢失。单页采集仍保留在“单页采集与手动导入”中。

扩展只读取当前页面已经显示的公开职位卡片，不读取账号、Cookie、聊天记录或站内简历，也不会自动投递。

### 手动导入备用方式

如果扩展因招聘网站页面改版暂时无法识别，可在结果页展开“单页采集与手动导入”，复制职位列表文字交给大模型解析。

如果已有形如下面的智联公开列表页，也可以展开“已有智联公开列表页？手动导入”直接读取：

```text
https://www.zhaopin.com/zhaopin/页面ID/
```

直接读取功能只允许 `www.zhaopin.com/zhaopin/.../` 的无参数 HTTPS 页面，每次读取单个页面，结果在内存缓存 30 分钟；不会访问智联内部 API、职位详情接口、登录页面或绕过验证码。粘贴的职位文字与简历画像会发送给所选大模型，具体信息以智联原页面为准。

### BOSS 手动导入

BOSS 直聘会对程序访问返回动态安全校验页，因此应用不自动抓取、不模拟搜索引擎，也不调用受限接口。上传简历后：

1. 展开结果页中的手动导入方式，选择“粘贴 BOSS 职位文字”。
2. 在浏览器打开 BOSS 公开招聘页，复制职位列表区域的可见文字。
3. 粘贴到应用中，由当前选择的千问或 DeepSeek 识别职位并匹配简历。

支持无参数的 `www.zhipin.com/zhaopin/.../` 和 `m.zhipin.com/zhaopin/.../` 公开页面。粘贴的职位文字与简历画像会发送给所选大模型；不会读取或发送 BOSS 的账号、Cookie、聊天记录。
