# 职得岗位采集助手

## 安装

1. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本文件夹。
4. 把“职得岗位采集助手”固定到浏览器工具栏。

## 使用

1. 保持本地助手运行：<http://127.0.0.1:8765>。
2. 在助手中上传简历，选择城市和岗位关键词。
3. 打开助手生成的智联或 BOSS 搜索页。
4. 页面显示职位后点击扩展图标，再点击“采集当前页岗位”。
5. 返回本地助手，岗位会自动完成去重、匹配和排序。

扩展只读取当前页面可见的公开职位卡片，不会读取账号、Cookie、聊天记录或站内简历，也不会自动投递。
