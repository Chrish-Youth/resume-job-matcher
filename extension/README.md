# 职得岗位采集助手

## 安装

1. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本文件夹。
4. 把“职得岗位采集助手”固定到浏览器工具栏。

## 使用

1. 保持本地助手运行：<http://127.0.0.1:8765>。
2. 在助手中上传简历，选择城市和岗位关键词。
3. 点击“开始自动找工作”（或勾选“分析完成后自动开始找工作”），扩展会在新页面自动切换搜索词并连续采集。
4. 每个关键词会自动采集最多 3 页、120 个岗位，逐页回传并去重。遇到验证码或登录页时会暂停；你完成处理、岗位重新显示后自动续跑，也可在助手中点击“已处理，继续雷达”。
5. 在助手中开启“定时雷达”后，扩展会在设定的每日时间自动启动一轮采集；完成后通过桌面通知告诉你新增了多少岗位。
6. 单页手动采集仍可点击扩展图标，再点击“采集当前页岗位”。
7. 返回本地助手，岗位会自动完成去重、匹配和排序。

当前版本为 1.4.0。更新后请在扩展管理页点击“重新加载”，并刷新已有招聘网页。
本地服务和招聘浏览器页需要保持运行；助手网页可以关闭，采集结束后后台会自动匹配，重新打开即可查看结果。
短暂断网时会自动重试；手动停止的任务不会因为自动重试而再次开始。

扩展只读取当前页面可见的公开职位卡片，不会读取账号、Cookie、聊天记录或站内简历，也不会自动投递。
